# aaditya420.github.io

Personal portfolio of Aaditya Verma: https://aaditya420.github.io/

A static site with no build step and no dependencies.

| File | What it does |
| --- | --- |
| `index.html` | All content |
| `css/style.css` | Layout, type and the glass surfaces |
| `js/fluid.js` | GPU fluid simulation behind the page |
| `js/particles.js` | Particle rendering of the name in the hero |
| `js/graph.js` | Force-directed skills graph |
| `js/main.js` | Scroll-driven effects, input and the frame loop |
| `Aaditya_Verma_Resume.pdf` | Downloadable resume |

To preview locally: `python3 -m http.server` and open http://localhost:8000.

Motion is off by default for visitors who ask their device to reduce motion, and anyone can pause it from the navigation bar.
